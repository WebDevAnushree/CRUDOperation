📝 Todo List - CRUD Operation (MERN)


📌 Project Overview
This project is a Todo List application built with the MERN stack — MongoDB, Express.js, React.js, and Node.js. It demonstrates how to implement CRUD (Create, Read, Update, Delete) operations in a full-stack JavaScript environment.


The application allows users to:

Create new todo tasks

Read and display all tasks

Update existing tasks (e.g., mark as completed or edit text)

Delete tasks permanently



🛠️ Tech Stack
MongoDB: Database for storing todos.

Express.js: Backend framework for building RESTful APIs.

React.js: Frontend library for interactive UI.

Node.js: Server-side runtime environment.

🚀 Features
RESTful API endpoints for CRUD operations.

Responsive React frontend with forms and task lists.

Integration with MongoDB for persistent storage.

Error handling and validation for robust data management.

Modular code structure for scalability and maintainability.
